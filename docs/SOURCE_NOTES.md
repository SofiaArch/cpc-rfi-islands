# 中油綠能研發大樓新建工程釋疑資訊平台

六角微縮模型城市，以 9 個主題島與 1 座研發中心呈現建築、機電釋疑資料。使用 Canvas 2D 投影真正的三維幾何，具備旋轉、俯仰、縮放、模型點選及鍵盤可操作的島嶼名牌，不依賴 WebGL。

每座島嶼有 3 位沿外圍步道移動的小人物，共 30 位，具踏步、擺臂與部分安全帽造型。城市動畫可暫停／繼續；偏好減少動態的裝置預設暫停。主標題為「讓我們攻略每一座問題島吧!」。

每個島嶼面板顯示「全部問題」、「已處理」與 HP 進度條。HP＝已處理／全部問題，處理越多，血量越滿。已處理定義為有回覆日期與內容的 RFI，待核對尚未計入 HP。桌面面板固定於模型兩側，小螢幕改列於模型下方；模型視窗與面板分區，旋轉及縮放時也不會被面板遮擋。滑鼠移入面板可標示對應島嶼。中心島顯示全案總覽，匯入新版 Excel 後同步重新計算。

## 互動與資料

- 157 筆 RFI：138 已回覆、18 待回覆、1 待核對；另外保留 98 筆審查／業主需求變更明細。
- 搜尋編號、主旨、回覆、專業、圖號；依主題、來源、狀態、變更篩選；排序、關注與 CSV 匯出。
- 各筆保留原表文字、民國日期、工作表與列號，及由寄信紀錄取得的附件／用印回覆連結。
- 19 個核定文件／資料夾入口及 NotebookLM 入口。未讀取 NotebookLM 內文。
- 支援匯入原格式 `.xlsx`，用瀏覽器原生 ZIP 解壓縮與 XML 解析，解析成功才整批換入。匯入與關注保存在該瀏覽器 localStorage。

資料基準：2026-10-27 使用者附上的建築、機電 Excel 快照，以及同日取得的核定文件目錄。未自動同步 Google Sheets 或 Drive；Sites 連接器適用性探索工具在此環境未提供。未變更 Google Drive 原檔、分享或權限。初始網站為擁有者私人存取。

統計依原表回覆日期與概要推導，已回覆不代表已結案；無契約回覆期限，因此顯示等待天數，不標示逾期。主題分類採文字規則，屬導覽用途，原表專業保留。缺日日期保留月份。寄信紀錄不重複計入 RFI。

## 參考站拆解與轉譯

參考：https://puma.taipei/heart-island

實際讀取到的互動結構包括：14 個六角政策島、政策主題／協作關係清單、搜尋、全景、時段、名牌、協作線、暫停動畫及鳥瞰操作。參考站在驗證瀏覽器出現 `Error creating WebGL context`，因此無法驗證其 3D 場景視覺與動畫細節。

本平台借鑑六角主題城市＋清單探索的架構，重新建立暖色幾何模型與工程資訊介面。主題數量、分類、狀態、附件及統計均以本案資料定義；未使用對方程式碼、模型或品牌素材。關聯以同 RFI 編號續辦顯示，未把空間鄰接宣稱為真實業務依賴。

## 檔案與驗證

`dist/index.html`、`dist/style.css`：響應式介面；`dist/city.js`：三維模型與投影；`dist/data-model.js`：正規化、日期與狀態；`dist/excel-reader.js`：本機 Excel 讀取；`dist/app.js`：介面行為；`dist/data.json`：來源資料；`dist/resources.json`：核定文件目錄。

執行 `npm run check` 驗證唯一編號、統計、日期、來源列號及附件。沒有外部 JavaScript 依賴，字型可回退至系統中文字型。


## 人物隨機提問

每輪最多兩位不同主題島的人物，使用該島真實 RFI 主旨、編號與狀態；優先待回覆，最近 12 筆避免重複（同島候選用盡時才允許再選）。第一輪約載入後 1 秒，每輪起始間隔 10–15 秒，顯示 5 秒。人物發言時停步，結束後從原位置繼續。泡泡隨相機投影並排開，限於模型視窗內；點選直接查看詳情。滑鼠停留或鍵盤聚焦會延長閱讀時間，閱讀詳情／清單時暫停提問，與城市暫停動畫同步。右上「提問」可關閉，偏好保留於該瀏覽器，不需 AI 或額外 API。
